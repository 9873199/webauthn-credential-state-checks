# Stateful passkey verification

AI-assisted post-session independent review. These files are separate from the native trajectory. Install dependency-lock.txt from the account-review-r1 output, put the frozen checkout and the selected test revision on PYTHONPATH, and run the commands in reviewed-spec.json. Python 3.14.3. No external service, browser or USB is used. Generated ephemeral P-256 private keys stay in memory. The registration-backup-boundaries command intentionally fails one required boundary; see original stdout and metadata. The recorded console is an openly labelled automated demonstration executing demo.py against the frozen product. It does not represent manual typing.
